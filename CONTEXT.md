## Shared identity

The family should feel scientific, modular, precise, spatial, extensible, calm in normal operation, and futuristic where information structure is visualized.

Shared across all products:

- typography
- theme palettes
- neutral palette
- accent family
- UI geometry
- spacing
- scientific visual language

Product-specific:

- symbol
- accent use
- domain visualization
- specialized components

## Accepted typography

- UI / supporting brand: **Sora**
- technical / mono: **IBM Plex Mono**
- logo wordmarks: dedicated geometric treatment from current concept direction

## UI language

Fluent-inspired desktop research software:

- mostly rectangular surfaces
- restrained corner radii
- subtle borders
- precise alignment
- calm application shell
- expressive scientific visualization

Avoid soft rounded dashboard styling and generic AI aesthetics.

## Current CScience direction

Claim: **Context. Coordinate. Features.**

Preferred symbol:

- open context circle
- central square coordinate
- relation rays
- structured square feature grid
- selected cells in active theme colors

`[1 0]` was explored and rejected as a logo element.

## Current SCIRE direction

SCIRE = **Scientific Contextual Indexing and Retrieval Engine**

Role: scientific research software backbone.

Primary idea: **Context × Coordinate × Feature**

Preferred graphical baseline:

- open context circle
- central square origin
- rays
- 3 × 5 feature grid
- theme-colored selected cells
- outlined unselected cells
- no crosshair

## Current SPOT direction

SPOT is a spatial video-search application powered by SCIRE.

Claim: **We spot what matters.**

Preferred symbol:

- CScience-family open-context geometry
- dog Spot as the approachable product-specific subject
- square feature grid
- highlighted local square region
- relations from subject/source toward the selected region

Keep this direction.
