# SCIRE

**Scientific Contextual Indexing and Retrieval Engine**

> **Status:** Strong current graphical concept; final vector artwork still open.

## Role

Scientific research software backbone owned by net.cscience.

## Primary idea

```text
Context × Coordinate × Feature
```

## Preferred graphical baseline

- open circular context space
- central square origin / coordinate
- relation rays
- 3 × 5 square feature grid
- selected feature cells use the active theme palette
- unselected cells remain outlined
- no crosshair construction

## Preferred lockup

```text
SCIRE
Scientific Contextual Indexing and Retrieval Engine
```

Optional endorsement:

```text
A net.cscience research platform
```

## Production status

The Illustrator-refined concept is the current baseline. Generated imagery and auto-traces are not final production artwork.
