# SPOT

> **Status:** Preferred current concept — keep this direction.

## Role

Novice-oriented spatial video-search research application powered by SCIRE.

## Claim

```text
We spot what matters.
```

## Product concept

SPOT searches for meaningful spatial regions in image and video content.

The dog Spot is an intentional approachable reference to the existing SPOT visual-search example.

## Preferred graphical concept

- reuse the CScience-family open-context geometry
- retain the shared square feature-grid language
- use the dog Spot as the product-specific subject
- highlight a local group of feature squares to represent the selected image region
- connect the source/subject to the selected region through the shared relation-ray language

## Product relationship
